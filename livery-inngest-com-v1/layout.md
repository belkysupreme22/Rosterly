# Layout

- Content sits in a 1440px container, centred.
- Sections breathe with about 160px of vertical padding on desktop.
- The header is 88px tall, sticks to the top and sits on a hairline border.
- Grids use 1, 2, 3 columns.
- Breakpoints at 380, 520, 639, 640, 768, 1024px; layouts collapse to one column on phones.
